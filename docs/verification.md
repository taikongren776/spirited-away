# 验收记录

日期：2026-10-25（Asia/Shanghai）

## 环境

- Windows 本地项目，Node.js 24.21.0，Vite 7.3.7，Three.js 0.180 系列。
- Codex 内置浏览器，支持 WebGL 2。
- 桌面视口：1920×1080；竖屏视口：390×844。
- 竖屏测试使用同一台桌面计算机的浏览器尺寸模拟，未使用真实手机。未独立核实 GPU 型号。

## 构建与测试

- `npm run build`：通过 TypeScript 检查及 Vite 生产构建。
- `npm test`：8 项测试全部通过。
- 测试覆盖减少动态效果时初始暂停、播放终点与重播、探索和 1.2 秒返回期间时间冻结、进度边界与非法输入、长帧保护、中断返回、四段镜头边界连续，以及桌面和竖屏路径避开建筑与桥面。
- 浏览器控制台：实际加载、播放、拖动及画质切换后，错误和警告日志为空。
- 生产资源合计约 156 kB gzip，全部资源可由本地静态服务提供。Three.js 分块略高于 Vite 默认的 500 kB 原始体积提醒阈值；这是体积提示，构建成功。

## 性能采样

| 视口 / 画质 | 前台 RAF 采样 | 渲染统计样本 |
| --- | --- | --- |
| 1920×1080 / 精细 | 约 240 FPS | 112–113 draw calls，约 616,000 三角形 |
| 390×844 / 流畅 | 约 240 FPS | 非倒影刷新帧约 58 draw calls，308,000 三角形 |

统计来自页面 `#app` 的每两秒采样；包含重复渲染的反射和后期处理，不代表模型独立三角形数，也不是跨设备性能保证。浏览器在后台或不可见时可能节流，后台读数不用于性能结论。手机 30 FPS 目标仍需在真实移动设备确认。

## 验证范围

已检查桌面/竖屏渲染、主要交互、完整播放及控制台。减少动态效果的时间轴行为有单元测试；系统偏好切换、双指手势、WebGL 上下文丢失、真实移动 GPU 和 Safari 兼容性未完成真机实测。
